# 🍽️ Swiggy Order & Revenue Performance Analysis

## 📌 Project Overview

This project presents an interactive Microsoft Excel dashboard designed to analyze Swiggy order and revenue performance. It transforms raw order data into meaningful business insights using dynamic charts, Pivot Tables, Pivot Charts, Slicers, and an India Map visualization.

---

## 🎯 Business Objective

The objective of this project is to analyze customer ordering behavior, restaurant performance, product categories, and revenue trends to support business decision-making.
